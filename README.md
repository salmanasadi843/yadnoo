#  یادنو (Yadnoo)

دفترچه یادداشت هوشمند فارسی با قابلیت همگام‌سازی ابری

## ✨ ویژگی‌ها

- 📚 ساختار سه‌لایه: دفتر ← بخش ← یادداشت
- 🔐 احراز هویت با Firebase
- ️ همگام‌سازی بین دستگاه‌ها
- 📱 PWA - قابل نصب روی موبایل و دسکتاپ
-  حالت روشن و تیره
- 📥 وارد کردن از OneNote
- 🗑️ سطل زباله با بازیابی
- 🔍 جست‌وجوی پیشرفته
-  سنجاق‌کردن یادداشت‌ها
- 🏷️ برچسب‌گذاری
- 📎 پیوست فایل
- 💾 پشتیبان‌گیری JSON

## 🚀 نصب

1. وارد [yadnoo](https://salmanasadi843.github.io/yadnoo/) شو
2. روی «Add to Home Screen» بزن (در موبایل)
3. یا از منوی مرورگر «Install» را انتخاب کن (در دسکتاپ)

## 🔧 راه‌اندازی Firebase

1. به [Firebase Console](https://console.firebase.google.com) برو
2. پروژه جدید بساز
3. Authentication → Email/Password را فعال کن
4. Firestore Database بساز
5. firebaseConfig را در تنظیمات اپ وارد کن

## 📥 وارد کردن از OneNote

فایل‌های `.one` پشتیبانی نمی‌شوند. از OneNote خروجی HTML یا MHT بگیر.

##  تکنولوژی‌ها

- HTML5 / CSS3 / JavaScript (Vanilla)
- Firebase (Auth + Firestore)
- PWA (Service Worker + Manifest)
- Vazirmatn Font
