اتصال به Firebase

برای اینکه یادداشت‌ها بین گوشی و کامپیوترت همگام بشن، این اپ به یک پروژه‌ی رایگان Firebase (متعلق به خودت) وصل می‌شه. این کار فقط یک‌بار لازمه.

  1. وارد console.firebase.google.com شو و یک پروژه‌ی جدید بساز
  2. از منوی سمت راست، Build → Authentication رو باز کن، تب Sign-in method، روش Email/Password رو فعال کن
  3. از منو، Build → Firestore Database رو باز کن و یک دیتابیس بساز (Start in test mode کافیه)
  4. روی آیکون تنظیمات (⚙) کنار «Project Overview» بزن → Project settings
  5. پایین صفحه، بخش «Your apps» → آیکون وب (</>) رو بزن، یک اپ وب اضافه کن
  6. کد firebaseConfig که نشون داده می‌شه رو کپی کن و همون‌جا (بین آکولادها) اینجا بچسبون
